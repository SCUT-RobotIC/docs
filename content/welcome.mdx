# RobotIC 知识库

这里是华南理工大学 RobotIC 机器人实验室的内部知识库。

知识库使用 Markdown/MDX 编写，由 Docusaurus 生成静态 HTML，并随主站一起发布到 GitHub Pages。

## 从这里开始

- 阅读[编写指南](./writing-guide)，了解如何新增和维护文档。
- 在左侧目录中浏览现有内容。
- 需要补充的文档可以直接在 `content/` 中创建。

## 内容原则

1. 一页只解决一个明确问题。
2. 示例、命令和参数应可以直接复制使用。
3. 涉及硬件、供电和机械安全的操作必须写明风险与前置条件。
4. 文档内容变化时同步更新相关链接，避免留下失效页面。
